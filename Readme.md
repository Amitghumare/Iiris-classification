# 🌸 Iris Flower Classification

## 📌 Project Overview
This project uses Machine Learning to classify iris flowers into three species:
- Setosa
- Versicolor
- Virginica

---

## 🧠 Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn
- Jupyter Notebook

---

## ⚙️ Machine Learning Model
- Algorithm: K-Nearest Neighbors (KNN)
- Data Scaling: StandardScaler

---

## 📊 Dataset
- Built-in Iris dataset from sklearn
- Features:
  - Sepal Length
  - Sepal Width
  - Petal Length
  - Petal Width
